# Bivdi — Attribution

**Status:** Decided (`D-001`). This is a commitment, not a suggestion. Preserve this text in public material.

---

## 1. The name

**Bivdi** is a North Sámi word derived from the verb **bivdit** ("to hunt, to fish; to ask for, to request"). The double meaning is the security model in one word: in a capability system nothing has ambient authority — everything must *ask*.

**Pronunciation.** Roughly **BIV-dee** (`/ˈpivdi/`). In Sámi orthography a word-initial *b* is typically realised unaspirated, closer to English *p*; both readings are accepted in the community.

**Domain.** [bivdi.com](https://bivdi.com).

---

## 2. Commitments

Bivdi is a Sámi word used by a project that is not a Sámi institution. The project therefore commits to:

1. **Getting it right.** Orthography, gloss, and pronunciation guidance in all public material will be reviewed by a competent authority before any 1.0 announcement. Corrections are shipped as errata, not quietly dropped.
2. **Crediting the source.** This section (or a condensed form) appears in the README, on the website, and in `--version` output. The name is never presented as invented or as generic "Nordic" branding.
3. **Not claiming representation.** Bivdi does not speak for, represent, or imply endorsement by Sámi people or institutions. No Sámi visual identity — no gákti patterns, no *goavddis* drum motifs, no flag colours — appears in project branding.
4. **Giving something back.** From first revenue or sponsorship, a standing annual contribution to Sámi-language digital infrastructure.
5. **Listening.** If Sámi language authorities or community representatives object to the use, the project renames. This is a real commitment: the cost of renaming a pre-1.0 project is small, and it is written here so no one later argues it is too late.

Points 4 and 5 are what separate a considered borrowing from an extraction. If any of them feels like too much to commit to, the project should rename before 1.0 rather than after.
